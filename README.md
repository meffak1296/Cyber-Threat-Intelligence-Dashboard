# 🛡️ Cyber Threat Intelligence Dashboard

## 📖 Project Overview

The Cyber Threat Intelligence Dashboard is an interactive web application developed using Streamlit. It helps security analysts visualize cyber attack data from the CICIDS2017 dataset through interactive charts, filters, and threat analysis.

---

## ✨ Features

- 📊 Interactive Dashboard
- 🎛️ Sidebar Filters
- 📁 Dataset Preview
- 🚨 Attack Type Analysis
- 📈 Attack Distribution Bar Chart
- 🥧 Attack Distribution Pie Chart
- 🏆 Top 5 Most Frequent Attacks
- ⚠️ Dynamic Threat Level
- 📥 Download Filtered CSV
- 📊 Attack Statistics
- 🚨 Threat Summary

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Plotly

---

## 📂 Dataset

- CICIDS2017 Cleaned Dataset

---

## 📸 Screenshots

Project screenshots are available in the `screenshots` folder.

---

## 🚀 How to Run

1. Install the required libraries:

```bash
pip install -r requirements.txt
```

2. Run the dashboard:

```bash
streamlit run dashboard.py
```
